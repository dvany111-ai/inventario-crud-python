# Sistema de inventario

Aplicación de consola en Python para administrar productos con una base de datos SQLite.

## Funcionalidades

- Registrar y ver productos.
- Actualizar y eliminar productos por ID.
- Buscar por ID, nombre o categoría.
- Consultar productos con stock igual o menor al límite elegido.

## Requisitos

- Python 3
- Colorama

## Instalación

Instalar Colorama con:

python3 -m pip install colorama

## Ejecución

Desde la carpeta donde está inventario.py, ejecutar:

python3 inventario.py

La base de datos inventario.db se crea automáticamente al iniciar el programa.
